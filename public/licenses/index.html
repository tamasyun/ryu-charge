写真処理のオープンソースライセンス

写真の変換には以下のライブラリを使用しています。ライブラリは改変せず、必要な際に独立したWorkerとして読み込みます。

  • heic-to 1.6.7 — Hopper Gee, LGPL-3.0-or-later。 ライセンス / GPL v3 / 対応するソースとビルド手順
  • libheif 1.23.7 — struktur AG and contributors, LGPL-3.0-or-later。 ライセンス / ソース
  • libde265 1.0.16 — struktur AG and contributors, LGPL-3.0-or-later。 ライセンス / ソース
  • ExifReader 4.54.0 — Copyright (C) 2011-2026 Mattias Wallander, MPL-2.0。 ライセンス / 対応するソース。画像の向きの判定に使用し、ライブラリは改変していません。
  • image-size 2.0.4 — MIT / 著作権表示 / ソース
  • @jsquash/webp 1.5.0 — Apache-2.0 / ソース。 内包するlibwebpはBSD-3-Clause / 著作権表示。
  • @xmldom/xmldom 0.9.12 — ExifReaderの任意依存。MIT / 著作権表示。
  • wasm-feature-detect — Apache-2.0 / 著作権表示

LGPLライブラリの変更・差し替え、およびそのデバッグに必要なリバースエンジニアリングを妨げません。 ソースは上記リンクから取得でき、heic-toのREADMEとesbuild.mjsで再ビルドできます。 このアプリの依存パッケージheic-toを互換APIを持つ変更版に差し替え、npm run buildで再構築できます。
